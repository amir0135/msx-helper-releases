# MSX Helper — downloads

Download the latest version from **[Releases](https://github.com/amir0135/msx-helper-releases/releases/latest)**:

- **Windows:** `MSX-Helper-Setup-<version>.exe` (installer) or `MSX-Helper-<version>-portable.exe`
- **macOS:** `.dmg` — `arm64` for Apple Silicon, `x64` for Intel. First launch: right-click the app → **Open**.

Installed apps update automatically from this repo. This repo contains release binaries only.
